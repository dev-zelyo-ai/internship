### Easy Example: Calculating the Value of Stocks Using Python

Imagine you own 10 shares of a company, and each share costs ₹150. You want to know the total value of your investment.

**Python Code Example:**

```bash
python*# Number of shares you own*
number_of_shares = 10

*# Price of each share*
price_per_share = 150

*# Calculate the total investment value*
total_value = number_of_shares * price_per_share

print("The total value of your stocks is: ₹", total_value)
```

**What this does:**

- Defines how many shares you have and their price.
- Uses multiplication to find your total investment.
- Prints the answer in an easy-to-understand message.

## Simple Case Study: Analyzing Stock Price Changes with Python

Let's say you want to see if your favorite stock (for example, Reliance) has gone up or down over the last few days. You have the closing prices for a week:

- Monday: ₹2000
- Tuesday: ₹2020
- Wednesday: ₹2010
- Thursday: ₹2035
- Friday: ₹2040

**Python Code Example:**

```bash
python*# List of closing prices for each day*
prices = [2000, 2020, 2010, 2035, 2040]

*# Find how much the price increased or decreased each day*
for i in range(1, len(prices)):
    change = prices[i] - prices[i-1]
    print(f"Day {i}: Change in price is ₹{change}")
```

**What this does:**

- Stores daily prices in a simple list.
- Calculates price difference each day.
- Prints out the change for each day in rupees.
